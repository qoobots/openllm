# OpenLLM - 大模型垂直领域微调工程集合

基于Python+PyTorch的10个大模型垂直领域微调商业落地项目。

## 项目概览

本项目包含10个针对不同垂直领域的大模型微调工程，严格遵循PEFT技术标准，聚焦金融、医疗、制造和法律等强监管行业。每个项目均采用业界先进的微调技术，针对特定领域的痛点和需求进行深度优化。

## 技术特性

### 微调技术栈

| 技术 | 说明 | 优势 |
|------|------|------|
| **LoRA/QLoRA** | 低秩自适应微调 | 降低微调成本至200美元以内，仅需少量参数训练 |
| **DAPT** | 领域自适应预训练 | 使模型快速适应特定领域知识和术语 |
| **SFT** | 监督微调 | 使用标注数据学习特定任务能力 |
| **DPO/DKPO** | 偏好优化/去偏见优化 | 提升模型输出质量，降低偏见，符合公平性要求 |
| **RAG-Finetuning** | 检索增强微调 | 融合外部知识库，动态更新知识 |
| **联邦学习** | 分布式协作训练 | 数据不出域，实现跨机构知识共享 |

## 快速开始

### 环境要求

- **操作系统**: Linux (推荐Ubuntu 20.04+) / Windows 10+
- **Python**: 3.9+
- **CUDA**: 11.8+
- **GPU**: 建议使用A100/H100，最低使用RTX 3090 (24GB)

### 1. 选择项目并进入目录

```bash
cd 10-financial-compliance-finetune  # 或其他项目
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

依赖包包括：
- PyTorch >= 2.0.0
- Transformers >= 4.35.0
- PEFT >= 0.7.0
- BitsAndBytes >= 0.41.0
- 其他领域专用包（MONAI、Flower等）

### 3. 准备数据

将训练数据放入 `data/` 目录，格式参考各项目的配置文件和data_processor.py。

数据格式示例（JSONL）：
```json
{
  "field": "领域信息",
  "input": "输入内容",
  "output": "预期输出",
  "metadata": {"key": "value"}
}
```

### 4. 配置训练参数

编辑 `configs/config.yaml`，根据实际情况调整：
```yaml
training:
  batch_size: 8
  learning_rate: 2.0e-4
  num_epochs: 3

model:
  path: "path/to/base/model"
  use_lora: true
```

### 5. 训练模型

```bash
# 完整训练流程（所有阶段）
python scripts/train.py --config configs/config.yaml --stage all

# 仅执行特定阶段
python scripts/train.py --config configs/config.yaml --stage sft
```

支持的阶段：
- `dapt` - 领域自适应预训练
- `sft` - 监督微调
- `dpo` - 偏好优化
- `federated` - 联邦学习
- `all` - 完整流程

### 6. 推理测试

```bash
python scripts/infer.py \
    --model_path models/finetuned_model \
    --input "测试输入" \
    --output result.txt
```

### 7. 模型评估

```bash
python scripts/evaluate.py \
    --model_path models/finetuned_model \
    --test_data data/test.jsonl
```

## 技术栈详解

### 核心框架

```yaml
深度学习框架:
  PyTorch: >= 2.0.0          # 核心深度学习框架
  torchvision: >= 0.15.0      # 计算机视觉
  torchaudio: >= 2.0.0        # 音频处理（如需要）

大模型生态:
  Transformers: >= 4.35.0      # Hugging Face模型库
  PEFT: >= 0.7.0              # 参数高效微调
  BitsAndBytes: >= 0.41.0      # 4bit量化
  Accelerate: >= 0.24.0        # 分布式训练加速
```

### 微调技术实现

```yaml
LoRA/QLoRA:
  - 低秩分解：仅训练0.1%-1%的参数
  - 4bit量化：显存需求降低75%
  - 混合精度训练：FP16/BF16加速
  - 适配层：Q, K, V, O, Gate等关键层

三阶段微调:
  1. DAPT (Domain Adaptive Pre-training)
     - 使用领域语料预训练
     - 学习领域特定知识和术语
     - 时长：1-2 epochs
  
  2. SFT (Supervised Fine-tuning)
     - 使用标注数据监督训练
     - 学习特定任务能力
     - 时长：3-5 epochs
  
  3. DPO/DKPO (Direct Preference Optimization)
     - 使用偏好对优化
     - 提升输出质量和公平性
     - 时长：2-3 epochs
```

### 分布式训练

```yaml
Accelerate:
  - 多GPU数据并行
  - 梯度累积
  - 混合精度训练

Flower (联邦学习):
```

## 常见问题

### Q1: 如何选择合适的项目？
A: 根据您的业务领域和需求：
- 金融合同审查 → 项目1（合规）、项目6（反欺诈）、项目10（公平性）
- 医疗影像诊断 → 项目2（误诊优化）、项目5（医保合规）、项目9（基层医疗）
- 制造质检预测 → 项目3（质检）、项目8（预测维护）
- 法律合同审查 → 项目4（中文）、项目7（多语言）

### Q2: 训练需要多少数据？
A: 取决于任务复杂度：
- 简单任务（分类）：1,000-5,000条
- 中等任务（生成）：5,000-20,000条
- 复杂任务（多轮对话）：20,000-100,000条
- 领域自适应预训练：100,000+条

### Q3: 如何降低训练成本？
A: 采用以下策略：
- 使用LoRA/QLoRA：仅需训练0.1%-1%参数
- 4bit量化：显存需求降低75%
- 梯度累积：使用大batch size而无需大显存
- 联邦学习：分散训练成本到各节点

### Q4: 部署需要什么资源？
A: 推理阶段资源需求：
- 7B模型：16GB显存（量化后可降至4GB）
- 14B模型：32GB显存
- 70B模型：140GB显存（多卡）
- 多模态模型：根据图像分辨率

### Q5: 如何进行模型评估？
A: 使用项目提供的评估脚本：
```bash
python scripts/evaluate.py \
    --model_path models/finetuned_model \
    --test_data data/test.jsonl \
    --metrics accuracy,recall,f1
```

### Q6: 支持哪些推理框架？
A: 支持多种推理加速方案：
- PyTorch原生（简单易用）
- vLLM（高性能推理）
- TensorRT-LLM（极致性能）
- ONNX Runtime（跨平台）
- OpenVINO（Intel优化）
